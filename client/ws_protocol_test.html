使用说明
  1. 准备后端：redis / mysql → world（注册玩家，写入 Redis player:<name>）→ agent → game
  2. 填写玩家名 → 点「生成 JWT」（密钥与 game 的 TokenSecret 一致，默认 shared-secret-key）
  3. 连接 → 自动握手（发送 {"token","version"}）→ 收到 {"status":"ok"}
  4. 自动发送登录 CmdLogin，可手动重发 / 心跳 / 自定义消息
  5. 新增协议：在脚本 CMDS / BODY_SCHEMAS 登记即可复用本页测试
